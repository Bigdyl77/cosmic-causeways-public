COSMIC CAUSEWAYS 1.4.16 (web / mobile web app)

Upload this whole folder to any web host: itch.io (as an HTML game, zipped), GitHub Pages, Netlify or similar.
On phones, open the link, then:
  iPhone/iPad: Safari > Share > Add to Home Screen
  Android: Chrome > menu > Install app
It then runs fullscreen like an app and works offline after the first load.
To play on a computer, just double-click index.html.

The newest public build always lives at the same page:
https://github.com/Bigdyl77/cosmic-causeways-public
Play in the browser: https://bigdyl77.github.io/cosmic-causeways-public/

Title and pause menus include Your stats (saved profile history, available offline)
and Game-wide stats (anonymous daily totals; requires an internet connection).
Anonymous sharing can be turned off in Options > Gameplay > Share stats.
