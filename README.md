# Cosmic Causeways

This is the one page for the game. It always shows the newest public build, so this link does not change when the game does.

**Keep this link:** https://github.com/Bigdyl77/cosmic-causeways-public

## Play in the browser

https://bigdyl77.github.io/cosmic-causeways-public/

On a phone, open that link, then use **Add to Home Screen** (iPhone) or **Install app** (Android). The next time you open it, it picks up the newer copy.

## Download

- Browser (unzip, open the folder, then open `index.html`): https://github.com/Bigdyl77/cosmic-causeways-public/archive/refs/heads/main.zip
- Windows: [download the Setup installer](https://github.com/Bigdyl77/cosmic-causeways-public/releases/download/v1.4.13/CosmicCauseways-Setup-1.4.13.exe) (updates itself). Other downloads, including the portable edition that needs manual updates, are on the [releases page](https://github.com/Bigdyl77/cosmic-causeways-public/releases/latest).

Version 1.4.13 includes shared world records. Saves stay on your device when you replace the game files.

## Windows updates

[Download the latest Windows release](https://github.com/Bigdyl77/cosmic-causeways-public/releases/latest). Choose the Setup installer once to receive future update prompts inside the game. Press Alt, then Help → Check for updates. Save your run before restarting. The portable edition requires manual downloads.
